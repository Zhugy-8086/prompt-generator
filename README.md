# prompt-generator

纯前端（HTML + 原生 JS，`file://` 直接打开）的 AI 小说创作提示词生成器。把一段故事文本，自动提炼出氛围、伏笔、主角、世界观等维度，生成可直接喂给大模型的提示词。

> 当前版本：**V8.9.4**。历史与修复记录见 [`更新日志.md`](更新日志.md)。

> ⚠️ **玩具项目声明**：本项目是 AI 生成的玩具，别指望它真能干活——就当看个乐子，观察它会吐出什么稀奇古怪的东西。请勿把它的输出当作可信内容或正经的写作辅助，避免被误导。

## 特性

- 零依赖、零构建：双击 `prompt/prompt-tool-v8.9.html` 即可运行（IE11 有精简版 `prompt/tests/eliza-ie11.html`）
- 三种生成模式：综合 / 标准 / 反射
- HPDC8 置信度评分（异常度、氛围等维度，兼容降级为数字优先级）
- 伏笔引擎：长期 / 短期 / 疑似伏笔检测，Jaccard 相似度对比，字数漂移去重
- 主角识别：姓名、种族、等级、获取物、进化链五维档案
- 错误页分流与运行期降级（缺失模块时自动退避，不崩溃）

## 快速开始

直接用浏览器打开 [`prompt/prompt-tool-v8.9.html`](prompt/prompt-tool-v8.9.html)。
